# Janssen Mattress Site — V19

نسخة تطوير متجر مراتب يانسن مدينة نصر.

## أهم تحديثات V19
- مزامنة أسعار المقاسات من ملف `مراتب_يانسن(1).xlsx`.
- كتالوج 18 مرتبة مع بحث وفلاتر وترتيب بالسعر والاسم.
- تقسيم: سوست متصلة / سوست منفصلة / بدون سوست.
- صفحات معلومات عربية: التوصيل، الخصوصية، الاستبدال والاسترجاع، الشروط، من نحن.
- تحسين صفحات المنتج، الصور، الزوم، السحب، المقاسات، السلة، وواتساب.
- قسم FAQ ومزايا وطرق الدفع ومراجعات في الصفحة الرئيسية.
- نظام المراجعات: العميل يرسل الاسم والتقييم والنص والصورة الاختيارية؛ المراجعة تذهب إلى Google Sheet باسم `Reviews`، والصورة إلى Google Drive، وتظهر فقط بعد تغيير Status إلى `Approved`.

## Google Apps Script
استخدم `GOOGLE_APPS_SCRIPT_FINAL.js` مع نفس Web App URL الحالي. بعد تحديث الكود في Apps Script، اعمل Deploy > Manage deployments > Edit > New version.
